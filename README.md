# מפת בית המדרש

אפליקציית דף בודד ליצירת מפת ישיבה של בית המדרש: טורים של ספסלים, בימה, שולחן ארוך, ספסלים מאונכים — והכול ניתן לעריכה בלחיצה, בלי ידע טכני.

## איפה זה רץ

האתר הוא HTML סטטי אחד, בלי שרת ובלי התחברות — כל אחד שמקבל את הכתובת יכול לפתוח, לערוך, לייצא ולהדפיס.

האתר מתפרסם מענף `gh-pages` דרך GitHub Pages, ועולה בכתובת:
**https://ahiasaf.github.io/lapid/**

כל דחיפה לענף `gh-pages` מפרסמת גרסה חדשה תוך כדקה. אפשר גם לייבא את הריפו כמו שהוא ל‑Vercel או Netlify (אתר סטטי, בלי הגדרות בנייה).

## מה יש בפנים

- **`index.html`** — כל האפליקציה בקובץ אחד, ללא שרת וללא תלויות. אפשר גם לפתוח אותו ישירות מהמחשב.
- **`vendor/`** — הספריות ליצירת ה‑PDF (html2canvas, jsPDF), מקומיות כדי שהייצוא לא יהיה תלוי ברשת חיצונית.

## שמירה ושיתוף

- כל שינוי נשמר אוטומטית בדפדפן של העורך.
- **קישור לשיתוף** מקודד את המפה כולה לתוך הכתובת עצמה — שולחים את הקישור, והצד השני רואה בדיוק את אותה מפה ויכול להמשיך לערוך אותה אצלו.
- **גיבוי/שחזור** שומר את המפה כטקסט להעברה או לשמירה בצד.

## מה אפשר לעשות

- לחיצה על ספסל / בימה / שולחן פותחת עריכה: מספר כיסאות, שיוך כיתה, הוספה לפני/אחרי, שכפול, הזזה קדימה/אחורה ומחיקה.
- "החלת X כיסאות על כל הקטע" משנה בבת אחת את כל הספסלים ברצף (הבימה והשולחן מפרידים בין קטעים). כפתורי `+ טור` בקצוות מוסיפים טור.
- **מצב צביעה**: בוחרים כיתה בסרגל העליון (ז׳1–ז׳7, ח׳1–ח׳7) ולוחצים על ספסלים כדי לצבוע אזורים. רצף ספסלים מאותה כיתה מקבל מסגרת אחת עם שם הכיתה ומספר המקומות. המקרא בצד סופר אוטומטית מקומות וספסלים לכל כיתה, ולחיצה על הריבוע הצבעוני בו מחליפה את צבע הכיתה (ברירת המחדל — פלטה בלי ורוד).
- **פיצול ספסל**: מתוך חלון העריכה אפשר לשייך חצי ספסל לכיתה אחת וחצי לכיתה אחרת.
- **כיוון ספסל**: כל ספסל במפה יכול להיות "פנים קדימה" או "מאונך" (פנים הצידה), מתוך חלון העריכה.
- ↩ ביטול (גם Ctrl+Z), גיבוי/שחזור כטקסט, זום, והדפסה (A4 לרוחב) עם צבעים.

## פריסת ברירת המחדל

משמאל לימין: שלושה טורים של 13 ספסלים × 6 כיסאות; טור הבימה (6 ספסלים, הבימה, 5 ספסלים); הטור הימני — 7 ספסלים מאונכים צמודים לקיר הקדמי, רווח, 3 מאונכים, 2 עם הפנים קדימה (4 מקומות) ושולחן ארוך עם 20 מקומות; ולצידו, מוצמדת ומוסטת כלפי מטה, המובלעת הימנית — 4 ספסלים עם הפנים קדימה. ארון הקודש בחזית, ושתי כניסות — בקיר הימני ובקיר התחתון — מול הבימה.

כל ספסל יכול להיות "פנים קדימה" או "מאונך", ורצף מאונכים מוצג זה לצד זה. בכלי הטור אפשר להוסיף **רווח** בין קבוצות, **להזיז את הטור** למעלה/למטה, ו**להצמיד אותו לטור שלידו** — כך מתארים מובלעת שיושבת בצד ולא בקו אחד עם השאר. הכול ניתן לשינוי מתוך האפליקציה.
